PoS pilot and broader discovery universe — 16 November 2026
Project 1 | Public-source execution, not an estimated approval rate

RESULT
Completed an eight-program technical pilot and expanded into a reproducible discovery inventory across48 rare-disease search terms in8 disease families. The corrected all-phase inventory contains6,407 unique interventional trial records. This is a discovery panel, not a complete or representative census of all rare-disease development. Exact-name/condition buckets are provisional review units, not unique drug–indication programs.
No new broad or filtered approval probability is yet defensible. The limitation is incomplete program identity, entry-stage and outcome adjudication, not arithmetic or API access. A number based on COMPLETED versus TERMINATED trials or approved-name matches would answer the wrong question.

ACTUAL COMPUTATIONAL PIPELINE
1. Public ClinicalTrials.gov API v2: https://clinicaltrials.gov/api/v2/studies
   Query disease names, all interventional phases and study start through2024; paginate until no token. Include pre2010 records to detect earlier exposure. Retrieve identifiers, conditions, interventions/aliases/arms, sponsor, dates, phase, status and brief descriptions. No account/key used in this run. Keep original responses, URL parameters and hashes. This endpoint provides study records, not verified program outcomes or historical phase at first entry.
2. Public openFDA Drugs@FDA API: https://api.fda.gov/drug/drugsfda.json
   Pilot exact ingredient searches. Returned records for nusinersen, vosoritide and olipudase. No-hit for valoctocogene despite official FDA approval, so no-hit is unknown, never failure.
3. Official Drugs@FDA download: https://www.fda.gov/drugs/drug-approvals-and-databases/drugsfda-data-files
   Retrieved the6.1MB ZIP (12 text tables); match ingredient/brand names locally and extract original approval dates. Current local matching is exact, not fuzzy auto-adjudication. Original product approval may be for another indication; supplemental approvals and CBER products require separate checking. Original approval is not identical to orphan indication approval.
4. FDA orphan designations: public form exists, but the pilot returned a search form/503errors rather than valid records. This source is not silently treated as successfully retrieved. Orphan designation is not clinical entry anyway.
5. Python builds JSON evidence tables and a rebuildable SQLite workspace. Separate trials, intervention mentions, provisional program buckets, outcome evidence and eligibility flags. Missing classification remains null. Preserve all aliases and sponsors. Manual review is needed for collisions, background drugs, repurposing, indication subtypes and sponsor transfers.
6. Nested filter analysis will operate on the SAME adjudicated program rows: rare/non-oncology -> genetically defined CNS -> novel-target genetic medicine -> intrathecal protein restoration/neurodevelopment. No artificial multiplicative uplift from published17%.
7. A tested competing-risk estimator is implemented for fixed-horizon approval cumulative incidence. Confirmed permanent discontinuation competes with approval; unresolved cases end at verified last follow-up, not automatic failure or today's date. It rejects unverified eligibility/follow-up. It does not estimate unsupported lifetime tails or solve selection/missingness. It has been tested only on hand-calculated synthetic examples, not fitted to this unadjudicated inventory.

WHY NO PoS NUMBER YET
This panel is purposive and can overrepresent high-activity diseases; it cannot be labeled the all-rare-disease base rate. Condition searches miss healthy-volunteer entry studies and unregistered historical activity. Current phase labels are not original phase labels. Program discontinuation requires sponsor/regulatory evidence, and no update is not necessarily a failure. Ongoing programs require verified follow-up dates. Failure of a single trial is not failure of the drug–indication program. Treating FDA name matches as successes would create indication leakage.
The raw data therefore fails the pre-specified gate for an approval-rate denominator. It is suitable for candidate discovery and review prioritization, not valuation input. This is the pilot's substantive finding; adding more undifferentiated records would not fix it.
